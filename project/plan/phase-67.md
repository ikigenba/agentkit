# Phase 67 — `openai/subscription` consumes the raw token response; login flow deleted

*Realizes design Decision 25 (OpenAI credentials — the credential-file slice: R-PV6N-URM6, R-PWEK-8JCV, R-PXMG-MB3K). Depends on no pending phase (rewrites the already-built `openai/subscription` package).*

The package's one supported credential-file shape becomes the raw RFC 6749 token-endpoint response, verbatim — top-level `access_token`, `refresh_token`, `id_token`; other standard fields ignored. `Load` derives the account id from the `chatgpt_account_id` value under the `https://api.openai.com/auth` JWT claim (`id_token` first, `access_token` fallback; payload-only decoding, same posture as the existing `exp` peek) and fails loudly with distinct errors when `access_token` is missing (which is how a legacy codex-wrapper file fails) or when both JWTs lack the claim. Refresh rewrites the file atomically at 0600 in that same raw shape, carrying the prior `refresh_token` and `id_token` forward when the refresh response omits them, so a rewritten file always re-loads and re-derives the account id; the single-flight and atomic-write behavior already tagged R-DHHV-MCPJ is preserved, its test updated to assert the new written shape. The login flow — `BeginLogin`, `Flow`, `AuthorizeURL`, `Complete` — is deleted outright with no compatibility shim, along with its tests (tags R-I8OP-9XZ7 and R-I9WL-NPPW, ids design no longer mints). The live test tagged R-DJXO-DW6X is updated to gate on a raw-token-response credential file (skipping cleanly when absent) instead of a codex-compatible one. `openai.TokenSource` and the provider wire behavior (R-DG9Z-8KYU) are untouched.

**Done when:** R-PV6N-URM6, R-PWEK-8JCV, and R-PXMG-MB3K are covered by clearly-named tagged tests in `openai/subscription`; `grep -rn "BeginLogin\|AuthorizeURL\|R-I8OP-9XZ7\|R-I9WL-NPPW" --include='*.go' .` returns no matches; `grep -n "account_id" openai/subscription/subscription.go` returns no matches (the field no longer exists in any consumed or written shape); and the suite is green (`go build ./...`, `go vet ./...`, `go test ./...` all exit 0, `gofmt -l .` prints nothing).
