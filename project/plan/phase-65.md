# Phase 65 — Value-in/value-out login flow in `openai/subscription`

*Realizes design Decision 25 (OpenAI credentials — the login-flow slice: R-I8OP-9XZ7, R-I9WL-NPPW). Depends on no pending phase (extends the already-built `openai/subscription` package).*

The interactive `Login(ctx, path, LoginIO)` and the `LoginIO` type are removed outright — no compatibility shim — and replaced by the value-in/value-out flow D25 now specifies: `BeginLogin() (*Flow, error)` generates PKCE verifier/challenge and state and builds the authorize URL (pure computation, no network); `Flow.AuthorizeURL() string` exposes the URL as a value; `Flow.Complete(ctx, path, pastedRedirectURL)` parses the pasted redirect URL, verifies state, exchanges the code with the verifier at the token endpoint, and writes the auth file at path (0600). An empty or unparsable pasted line fails with an explicit error naming that the full redirect URL was expected — a distinct message from the wrong-`state` rejection — and neither failure sends a token-exchange request. After this phase the package's public surface contains no `io.Reader` or `io.Writer` and the package touches no terminal. `Load`/`Store`/`Token` and the refresh machinery are untouched. The old `Login` test (tagged R-DIPS-04G8, an id design no longer mints) is replaced by tests tagged with the two new ids.

**Done when:** R-I8OP-9XZ7 and R-I9WL-NPPW are covered by clearly-named tagged tests in `openai/subscription`; `grep -rn "LoginIO\|R-DIPS-04G8" --include='*.go' .` returns no matches; `grep -n "io.Reader\|io.Writer" openai/subscription/subscription.go` returns no matches; and the suite is green (`go build ./...`, `go vet ./...`, `go test ./...` all exit 0, `gofmt -l .` prints nothing).
