# Decision 6 — Generation settings and the native reasoning value

**Decision.** `Conversation.Gen` holds uniform sampling controls plus a **native-per-model** reasoning value. Reasoning is expressed in the *selected model's own* native term and values — there is **no** cross-model vocabulary and **no** translation. The provider layer is a dumb encoder (D5): the adapter lowers the consumer's `ReasoningValue` to its wire fields **by the value's shape alone** (level / budget / disabled / unset, D9) and sends it, consulting **no model knowledge**. A value the model accepts is honored exactly; one it does not accept is rejected by the **vendor**, surfacing as that provider's typed error (D7) — never a silent substitution, never an AgentKit-side fallback. Pre-send validation against a known model's vocabulary is available to consumers as an *advisory* catalog lookup (D26); nothing in the request path performs it.

The consumer sets reasoning with a tagged `ReasoningValue` carrying exactly one native form, so the value flows to the adapter untranslated:

```go
// GenSettings holds uniform generation controls. The zero value is "use each
// provider's defaults": nil/0/unset fields are omitted from the request.
type GenSettings struct {
    Temperature *float64       // nil → provider default (pointer so 0.0 is distinguishable)
    TopP        *float64       // nil → provider default
    MaxTokens   int            // 0 → adapter-supplied default (Anthropic requires a value)
    Reasoning   ReasoningValue // zero value = unset → model default, no reasoning fields sent
}

// ReasoningValue carries exactly one native reasoning form for the selected
// model, flowing to the adapter untranslated. The four states — unset, a native
// level string, a native token budget, explicit-disabled — are mutually
// exclusive by construction (unexported fields; built only via the constructors
// below). The zero value is "unset": send no reasoning fields at all.
type ReasoningValue struct { /* unexported: tag + level string + budget int */ }

func Level(s string) ReasoningValue    // a native level string: Level("high"), Level("xhigh"), Level("minimal")
func Budget(n int) ReasoningValue      // a native token budget: Budget(8000)
func DisableReasoning() ReasoningValue // explicit off; the adapter lowers it to its wire's native off-form
```

```go
conv.Gen.Reasoning = agentkit.Level("xhigh")     // sent natively; the vendor judges it for the selected model
conv.Gen.Reasoning = agentkit.Budget(8000)       // likewise
conv.Gen.Reasoning = agentkit.DisableReasoning() // the wire's off-form; a model that can't disable rejects it
```

The `Warning` struct remains the shared degrade-and-warn surface for the cases the dumb layer legitimately owns — **wire-level** knowledge (a wire that only supports `tool_choice=auto`; schema constructs a dialect cannot carry) and the **cost-unknown** case (D16). Model-knowledge warnings are gone with the model knowledge:

```go
// Warning records something the library could not do as asked and degraded
// visibly. Every field is meaningful for every warning kind.
type Warning struct {
    Setting string      // "tool_choice" | "tool_schema" | "cost"
    Code    WarningCode // classifiable reason
    Detail  string      // human-readable: what was asked / what is unknown, what was applied
}

type WarningCode int
const (
    WarnToolChoiceForced WarningCode = iota // forced tool_choice degraded to auto (wire supports only auto)
    WarnToolSchemaLossy                     // JSON-Schema keywords dropped at a dialect boundary (D4/D22)
    WarnCostUnknown                         // no cost source for this call; cost reported as 0 (D16)
)
```

Settled choices:
- **`ReasoningValue` is a tagged carrier with three constructors** (`Level`/`Budget`/`DisableReasoning`) and an unset zero value — no exported fields, so the four states cannot be combined or half-set. Mirrors the sealed-union idiom of `Block` (D3) and `Event` (D2).
- **`Level` takes a raw native string, not a typed enum.** The accepted set differs per model and there is no honest cross-model enum; under free-flow models (D5) the accepted set is not even knowable for uncataloged ids — the vendor is the judge.
- **`DisableReasoning()` is first-class**, not `Level("none")`/`Budget(0)` — *which* value means "off" is wire-specific (`thinking:{type:"disabled"}` vs `reasoning.effort:"none"` vs `thinkingBudget:0`); the consumer expresses intent and the adapter lowers it to its wire's off-form. A model that cannot disable rejects it with the vendor's error.
- **Unset (zero value) sends nothing.** An untouched `GenSettings` sends no reasoning fields, so a consumer who ignores reasoning is unaffected — and a non-reasoning model is safe by default even when uncataloged.
- **No AgentKit-side reasoning validation, fallback, or warning.** The former warn-and-default choke point required per-model specs the provider layer no longer holds (D5). Its replacement is honest fail-loud: the value is sent as given and the vendor's rejection is surfaced typed and attributable. The old promise's *spirit* — never silently misapplied — survives strengthened: nothing is ever substituted at all. Consumers wanting pre-send politeness (validate a `/set` before spending a round trip, render a model's vocabulary in `--help`) call the advisory catalog (D26), outside the request path.
- **Wire-level warnings survive; the enum shrinks and gains `WarnCostUnknown`.** `WarnToolChoiceForced` and `WarnToolSchemaLossy` encode knowledge about the *API shape*, which the dumb layer owns. `WarnReasoningUnsupported`/`WarnReasoningCannotDisable` are deleted with the model knowledge that powered them. `WarnCostUnknown` is minted for the D16 zero-cost path.
- **Pointers for `Temperature`/`TopP`** distinguish "unset" (omit) from a deliberate `0.0`. `MaxTokens int` with `0` → adapter-default (supplies Anthropic's required value).

**Rejected.**
- *Warn-and-fall-back-to-the-model's-default on an unsupported value* — the previous design. Requires a per-model spec registry in the provider layer, which is model knowledge (D5 evicts it), gates day-one models, and quietly substitutes a value the consumer did not choose. Vendor rejection is louder and truer.
- *A single neutral `ReasoningEffort` ordinal mapped per provider* — "nearest" is undefinable across a discrete enum and an integer budget; native-first is strictly more truthful.
- *`Level`/`Budget`/disabled as separate exported fields on `GenSettings`* — lets a consumer set more than one (ambiguous); the opaque carrier forbids it.
- *Overloading `Level("none")`/`Budget(0)` for disable* — forces the consumer to know each wire's off-token; `DisableReasoning()` carries the intent.
- *Plain `float64` temperature with a sentinel* — `0.0` is legal; pointer is unambiguous.
- *A sealed `Warning` interface with per-kind variants* — consumers only display warnings; one honest flat struct (D7 precedent) suffices.

**Verification.**
- R-P5U3-5CFZ — a `GenSettings` with `Temperature`/`TopP`/`MaxTokens` set reaches each provider's request with those values; leaving them nil/0 omits the parameter so the provider default applies.
- R-CUBS-CPMC — an adapter lowers any `ReasoningValue` by its shape alone and sends it without consulting model knowledge: no reasoning `Warning` is ever emitted, no fallback value is ever substituted, and a vendor rejection of an unaccepted value surfaces as that provider's typed error while the value that was sent remains exactly the one the consumer constructed (per-provider slices).
- R-T40A-VZQ7 — a `Level`/`Budget`/`DisableReasoning` value reaches the provider adapter as the exact native form it was constructed with, with no cross-model mapping applied between the consumer call and the adapter seam.
- R-T587-9RGW — an unset (zero-value) `Reasoning` omits all reasoning parameters from the built request and produces no `Warning`.
- R-T6G3-NJ7L — the four `ReasoningValue` states (unset, level, budget, disabled) are mutually exclusive: a value built by one constructor never presents as another at the adapter seam (e.g. a `Budget` value is not readable as a level).
- R-P9HS-ANO2 — a forced `tool_choice` against a Chat-Completions-wire provider that supports only `auto` degrades to `auto` and records a `Warning{Code:WarnToolChoiceForced}` rather than failing.
- R-PBXL-275G — when every requested setting is honored and a cost source exists, `Stream.Warnings()` is empty.
