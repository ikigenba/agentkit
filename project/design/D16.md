# Decision 16 — Dollar-cost accounting: the resolution seam

**Decision.** Cost is resolved **per round trip, in the orchestrator, from two consumer-visible sources in fixed precedence** — with a loud, warned zero when neither exists. Providers hold no price data (D5); the price row for table-costed vendors travels **beside the model string on the `Conversation`**, as a sibling field the consumer sets when it picks a model (typically one catalog lookup, D26):

```
resolution, per round trip:
  1. rt.ReportedCost()        — the provider stated the charge (OpenRouter, D24)  → use it
  2. Conversation.Pricing     — consumer-supplied rates for the selected model    → Pricing.Cost(usage)
  3. neither                  — Cost(0) + Warning{Setting:"cost", Code:WarnCostUnknown}
```

No path errors, no path blocks a model from running, and no zero is ever silent: the warning rides **every** affected round trip (and its D15 log record), because each turn's record must be individually honest — display-level deduplication is the consumer's presentation choice. The zero-cost path is the day-one escape hatch for a model whose rates aren't published yet; in steady use the catalog keeps the common path warned-free.

```go
// On Conversation (D1), sibling of Model — set both when picking a model:
Model   string
Pricing *Pricing // nil → no consumer-supplied rates; resolution falls through

// Pricing is one model's per-token rates, as one or more context-length tiers.
// Rates are nano-USD per token (1e-9 USD) — integer, so cost is exact with no
// float drift. Reasoning output bills at the Output rate. Pricing is a pure
// data shape: AgentKit ships maintained values in the catalog (D26), and a
// consumer may equally supply its own (negotiated rates, a proxy's prices, a
// day-one model's just-announced sticker).
type Pricing struct {
    // Tiers are ordered ascending by MinInputTokens; Tiers[0].MinInputTokens
    // is always 0 (the base tier). A turn is rated entirely at the highest
    // tier whose MinInputTokens <= the turn's total input tokens. Most models
    // have exactly one tier.
    Tiers []RateTier
}

// RateTier is the per-token rate set for one context band.
type RateTier struct {
    MinInputTokens int64 // inclusive lower bound on a turn's total input tokens
    InputUncached  int64
    CacheReadInput int64
    CacheWrite5m   int64
    CacheWrite1h   int64
    Output         int64 // reasoning output billed at this rate too
}

// Cost computes one turn's nano-USD cost: it selects the tier by the turn's
// total input tokens (InputUncached + CacheReadInput + CacheWriteInput), then
// rates every bucket at that tier. Centralizes tier selection + the math.
func (p Pricing) Cost(u Usage) Cost

// Cost is an amount in nano-USD. USD() converts only at display.
type Cost int64
func (c Cost) USD() float64

func (s *Stream) Cost() Cost            // this turn's resolved cost
func (c *Conversation) TotalCost() Cost // cumulative resolved cost over the conversation
```

For the selected tier `t`, cost = `InputUncached·t.InputUncached + CacheReadInput·t.CacheReadInput + CacheWrite5m·t.CacheWrite5m + CacheWrite1h·t.CacheWrite1h + (Output+ReasoningOutput)·t.Output`, integer math. `TotalCost()` is the sum of per-turn resolved costs (each turn rated by *its own* input size — correct under D10's stateless resend-history model). A multi-round-trip turn resolves each round trip independently and `Stream.Cost()` sums them.

Settled choices:
- **Reported beats supplied.** A provider that states the actual charge (OpenRouter reads it off every response, research §14.2) is the ground truth; consumer-supplied rates for that model are ignored for that call. This also makes the routed case self-correcting: a model reached *via* OpenRouter is costed by OpenRouter's figure, not by the direct-route table row the catalog may carry.
- **Supplied rates ride the `Conversation`, not the provider.** The provider layer holds no model knowledge (D5). Pairing `Model` with `Pricing` in one visible place, owned by the consumer, is the dumb-layer design: agentkit core cannot tell a catalog row from a hand-written one — that indistinguishability is the point.
- **No cost source ⇒ zero + `WarnCostUnknown`, never an error and never a silent zero.** Running is never gated on price data (product: day-one models). The warning (D6's enum) fires on every affected round trip and appears in every affected D15 record; a mid-conversation fix (set `Pricing`, or switch models) stops it with no dedup state.
- **Subscription-mode OpenAI turns cost exactly like API-key turns** — the same resolution over the same supplied rates. The figure is **notional API-rate-equivalent, not actual spend** (the subscription is flat-rate; the backend reports no cost — research §15.4). Documented on the D25 surface; deliberately **no flag** distinguishes it (operator decision): the consumer chose the mode and the docs state the semantics.
- **nano-USD integers** — exact accumulation, no float drift; `Cost.USD()` converts only at display.
- **Tiered pricing via `RateTier`** — a turn is rated wholly at the highest tier whose `MinInputTokens` it meets, matching how providers re-rate the entire request once the prompt crosses the threshold.
- **Reasoning bills at the output rate** (research §6.3) — `ReasoningOutput` priced with `Output`.
- **Cost surfaced** per-turn (`Stream.Cost()`), cumulative (`Conversation.TotalCost()`), and in the `summary` log record (D15) — unchanged surfaces over the new resolution.
- **The maintained rate data lives in the catalog (D26)**, not here and not in providers: this decision owns the *seam and the math*; the catalog owns the *values* and their golden tests.

**Rejected.**
- *Provider-owned pricing registries + a pre-turn `Pricing(model)` gate (`ErrInvalidConfig` for unknown ids)* — the previous design. Structurally guaranteed "no unpriced turn" but embedded a model list in every provider and made an unpriced model *unrunnable* — the day-one lag this redesign exists to kill.
- *Error (pre-flight or post-trip) when no cost source exists* — considered and firmly reversed: it re-gates day-one models on price data. Zero-plus-warning keeps fail-loud honesty without the gate.
- *A bare silent zero* — indistinguishable from "genuinely free" and from a tiny real cost; `TotalCost` would quietly under-report. The warning labels the zero.
- *A cost-basis flag distinguishing notional (subscription) from actual cost* — operator-rejected; one number everywhere, semantics documented where the mode is chosen.
- *Warn once per conversation instead of per turn* — requires warning-memory state in core serving cosmetics, and makes individual turn records lie; dedup is a display concern.
- *float64 USD* — float drift on accumulation.

**Verification.**
- R-CZ7D-VSL4 — when a round trip carries a `ReportedCost`, `Stream.Cost()` equals it and `TotalCost()` accumulates it, even when `Conversation.Pricing` is also set (reported beats supplied) and even when the reported figure is zero-adjacent but present.
- R-D0FA-9KBT — when no `ReportedCost` exists and `Conversation.Pricing` is set, `Stream.Cost()` equals `Pricing.Cost(usage)` for the turn's usage, integer math over the selected tier.
- R-D1N6-NC2I — when neither source exists, the turn still succeeds with `Stream.Cost() == 0` and exactly one `Warning{Setting:"cost", Code:WarnCostUnknown}` per affected round trip — repeated on every subsequent affected turn, present in each turn's D15 record, and absent again once `Pricing` is supplied.
- R-V2SM-WC8V — a turn whose total input tokens reach or exceed a tiered `Pricing`'s `MinInputTokens` threshold is rated wholly at the high tier; a turn **strictly below** the threshold is rated at the base tier. The boundary is inclusive on the high side — a turn whose total input equals `MinInputTokens` lands in the high tier.
- R-PVUO-X4DC — `TotalCost()` equals the sum of per-turn costs, and the `summary` log record carries it.
- R-PX2L-AW41 — `Cost.USD()` converts nano-USD to USD correctly.
